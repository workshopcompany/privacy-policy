Best Friend 개인정보 처리방침

시행일: 2026년 9월 13일

'Best Friend'(이하 '앱')는 이용자 여러분의 개인정보를 소중히 여기며, 개인정보보호법 등 관련 법령을 준수합니다. 본 처리방침은 앱이 어떤 정보를 처리하고 어떻게 보호하는지 설명합니다.

1. 수집·이용하는 정보

앱은 회원가입이 없으며, 이름·전화번호·주소·이메일 등 개인 식별 정보를 수집하지 않습니다. 광고 식별자(ADID)를 포함한 광고·추적 데이터도 수집·이용하지 않습니다.

1) 대화 내용 (텍스트)

  • 사용자가 입력한 메시지와 음성 인식 결과 텍스트는 AI 응답 생성 목적으로만 전송·처리됩니다.
  • 전송 경로: 앱 → 개발자가 운영하는 Cloudflare Workers 프록시 → OpenRouter(LLM 서비스) 및 해당 모델 공급사.
  • 프록시 서버는 응답 생성 목적으로 내용을 처리하며, 별도의 저장소에 보관하지 않습니다.

2) 음성 (마이크 권한)

  • 마이크 권한(RECORD_AUDIO)은 기기 내 Android 음성 인식(SpeechRecognizer)에만 사용됩니다.
  • 음성 오디오는 앱의 서버로 전송되거나 개발자가 저장하지 않습니다.

3) 기기 내 저장 정보

  • 대화 기록: 기기 내부 데이터베이스(Room)에만 저장되며, 앱의 '대화 기록 삭제' 기능 또는 앱 삭제 시 즉시 삭제됩니다.
  • 설정 정보(Cloudflare Worker 주소, API 키, 역할·목소리 프로필): 기기에만 저장되며 외부로 전송되지 않습니다.

2. 개인정보 처리 목적

  1. AI 대화 응답 생성 및 표시
  2. 음성 인식(기기 내 STT) 및 음성 합성(TTS) 출력
  3. 대화 기록의 기기 내 저장 및 복원 (사용자가 직접 삭제 가능)

3. 제3자 제공 및 처리 위탁

4. 보유 및 이용 기간

  • 서버: 응답 생성 후 즉시 폐기 (별도 보관 없음)
  • 대화 기록·설정: 기기에만 저장되며, 사용자가 삭제하거나 앱을 삭제할 때까지 보관

5. 이용자 권리

이용자는 언제든지 ① 앱 설정의 '대화 기록 삭제'로 기기 내 대화 기록을 삭제하고, ② 앱을 삭제하여 모든 기기 내 데이터를 제거할 수 있습니다. 전송된 대화 내용은 서버에 보관되지 않으므로 별도의 열람·삭제 요청 대상이 없습니다.

6. 미성년자 이용

본 앱은 만 13세 미만 아동을 대상으로 하지 않습니다. 만 13세 미만 아동은 앱을 사용하지 않도록 해 주세요.
